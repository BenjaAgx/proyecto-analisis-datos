## Instrucciones de Obtencion del Dataset
Debido a las restricciones de tamano de archivo de GitHub (el archivo dataset.csv pesa aproximadamente 164 MB), este conjunto de datos ha sido excluido de la sincronizacion mediante el archivo .gitignore.

Para ejecutar la solucion computacional localmente:

1. Acceda al enlace provisto en el archivo archivocsvlink.txt ubicado en esta misma carpeta para descargar el conjunto de datos original desde Google Drive.

2. Descargue el archivo CSV.

3. Guarde el archivo descargado directamente en esta carpeta (datos/) con el nombre exacto:
   dataset.csv

4. Una vez ubicado el archivo en datos/dataset.csv, ejecute el programa principal desde la raiz del proyecto mediante:
   python main.py
