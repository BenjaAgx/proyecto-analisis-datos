# Datos del proyecto

El conjunto de datos de turismo se encuentra en `dataset.csv` y está diseñado para apoyar análisis de tendencias, comparación regional y proyección de demanda.

## Procedencia
El archivo fue generado para fines académicos y no representa una fuente oficial de turismo.

## Cómo obtenerlo
- El archivo está disponible en esta carpeta.
- Si se desea recrearlo, usar la estructura:
  año,mes,region,nacionalidad,visitantes,pernoctaciones,tasa_ocupacion,temporada

## Uso permitido
El dataset es sintético y no contiene datos personales ni sensibles.
